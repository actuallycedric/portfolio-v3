live stock tracker (wip)

spring boot · react · postgresql · websockets

a spring boot backend polls finnhub every 15 seconds and broadcasts the latest prices to every connected client over websockets (stomp), so the ui updates live without refreshing. prices are saved to postgres, so the app loads with the last known prices and the chart still shows recent history after market close.

bank api

spring boot · postgresql · testcontainers

a rest api rebuild of my earlier cli bank app. accounts support deposits, withdrawals, and transfers, with paginated transaction history. invalid requests return clear 400 / 404 / 409 errors, and transfers run in a single transaction so a failure never leaves one account debited without the other credited. integration tests run against a real postgres instance in docker via testcontainers.
